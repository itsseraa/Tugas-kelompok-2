SISTEM INFORMASI INVENTORI (SIFIN)

## 1. Tentang Proyek

SIFIN (Sistem Informasi Inventori) merupakan aplikasi berbasis web yang dibuat untuk membantu proses pengelolaan dan pencatatan persediaan barang. Aplikasi ini dikembangkan sebagai proyek kelompok pada mata kuliah Rekayasa Perangkat Lunak (RPL).

Sistem ini dirancang untuk mempermudah pengguna dalam mengelola data barang, mencatat barang masuk dan keluar, serta mengatur proses peminjaman barang agar data inventori tersimpan dengan lebih terstruktur.

## 2. Tujuan Aplikasi

Tujuan dari pembuatan aplikasi SIFIN adalah:

- Mempermudah proses pengelolaan data inventori barang.
- Membantu pencatatan barang masuk dan barang keluar.
- Mempermudah pengelompokan barang berdasarkan kategori.
- Mengelola informasi supplier dan satuan barang.
- Membantu proses pencatatan peminjaman barang.
- Menyimpan data inventori dalam database agar lebih terorganisir.

## 3. Fitur Aplikasi

Aplikasi SIFIN memiliki beberapa fitur utama, yaitu:

1. **Login:** Digunakan untuk masuk ke dalam sistem berdasarkan akun pengguna.
2. **Dashboard:** Menampilkan halaman utama aplikasi.
3. **Data Pengguna:** Mengelola informasi pengguna sistem.
4. **Data Barang:** Mengelola informasi dan persediaan barang.
5. **Kategori Barang:** Mengelompokkan barang berdasarkan jenisnya.
6. **Satuan:** Mengatur satuan yang digunakan pada barang.
7. **Supplier:** Mengelola data pemasok barang.
8. **Barang Masuk:** Mencatat penambahan barang ke inventori.
9. **Barang Keluar:** Mencatat pengeluaran barang dari inventori.
10. **Peminjaman:** Mencatat dan mengelola transaksi peminjaman barang.

## 4. Teknologi yang Digunakan

Teknologi yang digunakan dalam pengembangan aplikasi SIFIN meliputi:

- PHP sebagai bahasa pemrograman sisi server.
- MySQL sebagai sistem pengelolaan database.
- HTML untuk menyusun struktur halaman web.
- CSS untuk mengatur tampilan aplikasi.
- JavaScript untuk mendukung interaksi pada halaman.
- AdminLTE sebagai template antarmuka.
- Laragon sebagai lingkungan pengembangan lokal.
- Visual Studio Code sebagai editor kode program.

## 5. Database

Aplikasi SIFIN menggunakan database MySQL dengan nama database `sifin`.

File database hasil export tersedia dalam repository dengan nama `sifin.sql` dan dapat diimpor melalui phpMyAdmin.

## 6. Cara Menjalankan Aplikasi

1. Install aplikasi Laragon.
2. Salin folder SIFIN ke dalam direktori `www` pada Laragon.
3. Jalankan Apache dan MySQL.
4. Buka phpMyAdmin.
5. Buat database dengan nama `sifin`.
6. Import file `sifin.sql` ke dalam database tersebut.
7. Sesuaikan konfigurasi koneksi database pada aplikasi.
8. Jalankan aplikasi melalui browser sesuai alamat lokal yang telah dikonfigurasi.
